# P-map prior tool

Static website for the P-map prior tool (AMP 2026): compute Gaussian priors for
*MAP faithfulness constraints from infant discrimination data.

This repository only hosts the built page, `index.html`, served with GitHub Pages.
It is generated by `scripts/build_prior_tool.py` in the research repository and
published with `scripts/publish_prior_tool.py`; do not edit `index.html` by hand.
